# Taverna RPG Manager

## 📋 Sobre o projeto

O Taverna RPG Manager é um aplicativo mobile desenvolvido para auxiliar no
gerenciamento de informações relacionadas a campanhas de RPG.

## 🎯 Objetivo

O objetivo do projeto é facilitar a organização das informações utilizadas
durante uma campanha de RPG, permitindo que os dados sejam gerenciados
de forma prática pelo aplicativo.

## 🛠️ Tecnologias utilizadas

- React Native
- JavaScript
- TypeScript
- QuickSQLite
- Android
- iOS

## 📁 Estrutura do projeto

- `src/` — código principal da aplicação
- `Android/` — arquivos relacionados ao Android
- `iOS/` — arquivos relacionados ao iOS
- `__tests__/` — testes do projeto
